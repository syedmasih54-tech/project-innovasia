3 One Payment, One Decision Flow

1. Ingest Payment arrives (sender, receiver, amount, time, device).
2. State O(1) memory lookup for sender and receiver history.
3. Score LightGBM + Isolation Forest blend gives probability p.
4. Cost Compares Expected Loss vs Customer Checkout Friction.
5. Reasons TreeSHAP calculates top 3 plain reasons for flagged payments.
6. Commit Write decision to log, then update account memory in RAM.
